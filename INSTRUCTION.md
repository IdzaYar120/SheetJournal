# Інструкція з користування генератором навчальних журналів (Academic Journal Generator)

Цей сервіс призначений для автоматичного створення структурованих Google Sheets журналів успішності студентів на основі вхідних файлів у форматі Excel (`.xlsx`, `.xls`) або CSV.

Створені журнали повністю відповідають структурі відомостей та журналів, включаючи автоматичні підрахунки балів, формули переведення у шкалу ECTS/Національну, відомості з ініціалами студентів та зведені таблиці успішності.

---

## 🛠 1. Підготовка та встановлення

### Крок 1. Перевірка вимог
Переконайтеся, що на вашому комп'ютері встановлено:
- **Python 3.10+**
- Доступ до Інтернету для підключення до API Google Sheets.

### Крок 2. Налаштування віртуального оточення та бібліотек
Запустіть термінал (або PowerShell) у папці проекту та виконайте команди:
```bash
# Створення віртуального оточення (якщо не створено)
python -m venv venv

# Активація віртуального оточення
# Для Windows (PowerShell):
.\venv\Scripts\activate
# Для macOS/Linux:
source venv/bin/activate

# Встановлення необхідних бібліотек
pip install -r requirements.txt
```

### Крок 3. Налаштування ключів Google Sheets API (`credentials.json`)
Для взаємодії з Google Таблицями сервісу потрібні права доступу сервісного акаунту:
1. Перейдіть до [Google Cloud Console](https://console.cloud.google.com/).
2. Створіть новий проект (або виберіть існуючий).
3. Увімкніть **Google Sheets API** та **Google Drive API** для проекту.
4. Перейдіть у розділ **Credentials** (Облікові дані) -> **Create Credentials** -> **Service Account** (Сервісний акаунт).
5. Створіть сервісний акаунт, перейдіть на вкладку **Keys** (Ключі), натисніть **Add Key** -> **Create new key** у форматі **JSON**.
6. Завантажений JSON-файл перейменуйте в **`credentials.json`** та покладіть у кореневу папку проекту `exel_fill/` (поруч із файлом `google_sheets.py`).

## 📄 2. Вимоги до вхідного файлу даних

Вхідний файл (наприклад, `.xlsx`) має містити таблицю групи зі списком студентів та дисциплін.

### Структура таблиці:
1. **Рядок 1 (Назва групи):** В одному з перших стовпчиків має бути слово `Група` (або `Назва групи`), а в сусідній комірці праворуч — її назва (наприклад: `МН-11`).
2. **Шапка таблиці (Рядок 3 або поруч):** Має містити стовпчик із ключовим словом `ПІБ` (або `Прізвище`, `Студент`), а також назви всіх дисциплін у наступних стовпчиках.
3. **Кількість пар (занять):** У рядку кожного студента навпроти дисципліни вказується кількість занять для цієї дисципліни (наприклад, `16` або `32`).

### 🔍 Автоматичне визначення типу контролю за назвою дисципліни:
- Якщо назва стовпчика містить слова `курсов` або скорочення `кр`/`кп` — сервіс створює для цієї дисципліни аркуші курсового проекту (**`КР_*_Зміст`** та **`КР_*_Захист`**).
- Якщо назва містить слово `екзамен` або скорочення `екз` — дисципліна вважається **Екзаменом** (50 балів розподіляється на лекції/практичні, 40 балів виділяється на екзамен).
- В інших випадках тип контролю вважається **Заліком** (80 балів на семестрові заняття, 10 балів на ІНДЗ, 10 балів на додаткові активності).

## 💻 3. Запуск та користування сервісом

### Крок 1. Запуск локального сервера
Виконайте команду у віртуальному оточенні:
```bash
python app.py
```
У консолі з'явиться повідомлення, що сервер запущено на `http://127.0.0.1:5000/`.

### Крок 2. Завантаження файлу
1. Відкрийте браузер і перейдіть за адресою: `http://127.0.0.1:5000/`.
2. Натисніть **"Обрати файл"**, виберіть ваш Excel-файл та натисніть кнопку **"Завантажити та розібрати файл"**.

### Крок 3. Попередній перегляд та налаштування доступу
На сторінці передогляду ви побачите знайдену назву групи, список студентів та розібрані дисципліни:
1. **Введіть пошту власника (Gmail)** у полі *"Пошта для надання доступу"* — на цей акаунт буде надіслано права доступу на редагування створеного журналу.
2. *(Опціонально)* Введіть **ID папки Google Drive**, якщо хочете, щоб файл автоматично зберігся у вашій структурованій папці на Диску.
3. **Введіть Email викладачів** навпроти кожної дисципліни. Система автоматично надасть кожному викладачеві права доступу на редагування журналу, щоб вони могли самостійно вносити бали.
4. Перевірте та натисніть кнопку **"Створити Google Таблицю"**.

### Крок 4. Успішне створення
Після обробки система покаже сторінку успіху із посиланням на вашу нову Google Таблицю. Натисніть на посилання для переходу до журналу.

## 📊 4. Розуміння структури згенерованого журналу

Кожен створений журнал містить наступні аркуші:

1. **`ПК_{Дисципліна}`** (Поточний Контроль):
   - Аркуш для оцінювання по кожному дню занять.
   - Стовпчики чергуються: лекція (`л` — 0 балів) та практичне заняття (`п` — бали автоматично розподіляються пропорційно так, щоб сума за семестр дорівнювала макс. 80 балів для заліку або 50 балів для екзамену).
   - Студенти на всіх аркушах, крім першого, автоматично синхронізовані з першим за допомогою посилання `='ПК_{Перша}'!B5`.
2. **`КР_{Дисципліна}_Зміст` та `КР_{Дисципліна}_Захист`** (для курсових проектів):
   - Таблиці оцінювання комісії з 3 членів для детальної перевірки структури та безпосередньо захисту курсової роботи.
3. **`РК1` та `РК2`** (Рубіжний контроль):
   - Автоматично вираховує суму балів, відсоток накопичення та оцінку ECTS/Національну за першу і другу половину семестру.
4. **`ДОД_РК1`, `ДОД_РК2`, `ІНДЗ`, `ДОД_ІНДЗ`** (Додаткові відомості):
   - Журнали обліку додаткових балів та балів за індивідуальні домашні завдання (ІНДЗ макс. 10.0 балів).
5. **`СК`** (Семестровий Контроль):
   - Консолідує семестрові бали студентів на основі сум з РК1, РК2, ІНДЗ та додаткових аркушів.
6. **`В_{Дисципліна}`** (Заліково-екзаменаційні відомості):
   - Аркуші, підготовлені до друку згідно з вимогами університету.
   - ПІБ студентів автоматично скорочується до формату з ініціалами (наприклад: *Козак Є. В.*).
   - Містить формули оцінок («Відмінно», «Зараховано», шкалу ECTS) та повну статистику успішності групи наприкінці аркуша.
7. **`Відомості`** (Зведена семестрова таблиця):
   - Підсумковий дашборд групи, який показує накопичені бали та ECTS/Національну оцінку з усіх дисциплін одночасно.
