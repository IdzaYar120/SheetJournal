# Інструкція з користування генератором навчальних журналів (Academic Journal Generator)

Цей сервіс автоматично створює готовий **.xlsx-файл** журналу успішності студентів на основі вхідних файлів (Excel, CSV, Word) — з усіма вкладками, автоматичними підрахунками балів, формулами переведення у шкалу ECTS/Національну та зведеними таблицями успішності.

Жодного налаштування Google-акаунту, API-ключів чи хмарних сервісів не потрібно. Готовий файл можна одразу перетягнути у Google Drive (він автоматично стане Google Таблицею) або просто відкрити в Excel.

---

## 🛠 1. Підготовка та встановлення

### Крок 1. Перевірка вимог
Переконайтеся, що на вашому комп'ютері встановлено **Python 3.10+**.

### Крок 2. Налаштування віртуального оточення та бібліотек
Запустіть термінал (або PowerShell) у папці проекту та виконайте команди:
```bash
# Створення віртуального оточення (якщо не створено)
python -m venv venv

# Активація віртуального оточення
# Для Windows (PowerShell):
.\venv\Scripts\activate
# Для macOS/Linux:
source venv/bin/activate

# Встановлення необхідних бібліотек
pip install -r requirements.txt
```

### Крок 3. (Опціонально) Імпорт із Google Docs
Якщо плануєте користуватись вкладкою «Імпорт з Google Docs» (не обов'язково — основний спосіб роботи не потребує Google взагалі), для неї потрібна авторизація. Найпростіший спосіб — встановити [Google Cloud CLI](https://cloud.google.com/sdk/docs/install) і виконати:
```powershell
gcloud auth login
gcloud services enable drive.googleapis.com
gcloud auth application-default login --scopes="openid,https://www.googleapis.com/auth/userinfo.email,https://www.googleapis.com/auth/drive"
```
Якщо ця вкладка не потрібна — просто пропустіть цей крок.

## 📄 2. Вимоги до вхідного файлу даних / документа

Вхідні дані можна завантажити у вигляді файлу Excel (`.xlsx`, `.xls`), CSV (`.csv`), документа Word (`.docx`) або імпортувати напряму з **Google Docs**.

### Структура таблиці (у файлі чи Google Документі):
1. **Назва групи:** В одному з перших рядків (або абзаців у документах) має бути слово `Група` (або `Назва групи`), а поруч чи через двокрапку — її назва (наприклад: `МН-11`).
2. **Шапка таблиці:** Має містити стовпчик із ключовим словом `ПІБ` (або `Прізвище`, `Студент`), а також назви всіх дисциплін у наступних стовпчиках.
3. **Кількість пар (занять):** У рядках студентів під кожною дисципліною має бути вказано загальну кількість занять (наприклад, `16` або `32`).

### 🔍 Автоматичне визначення типу контролю за назвою дисципліни:
- Якщо назва стовпчика містить слова `курсов` або скорочення `кр`/`кп` — сервіс створює для цієї дисципліни аркуші курсового проекту (**`КР_*_Зміст`** та **`КР_*_Захист`**).
- Якщо назва містить слово `екзамен` або скорочення `екз` — дисципліна вважається **Екзаменом** (50 балів розподіляється на заняття, 40 балів виділяється на екзамен).
- В інших випадках тип контролю вважається **Заліком** (80 балів на семестрові заняття, 10 балів на ІНДЗ, 10 балів на додаткові активності).

## 🎓 2а. Пакетне створення журналів зі Списку студентів + РНП

Для масового створення журналів одразу для кількох груп однієї спеціальності передбачено окремий режим — вкладка **«Список + РНП»** на головній сторінці. Це найзручніший спосіб, якщо в деканаті вже є два стандартні документи університету:

1. **Список студентів** (`.doc`/`.docx`) — один файл з усіма групами й курсами (може містити кілька спеціальностей одразу). Формат: назва групи (наприклад `МН-31`) в окремому рядку, під нею — нумерований список ПІБ студентів.
2. **РНП (Робочий навчальний план)** (`.doc`/`.docx`) — офіційний план однієї спеціальності на весь термін навчання, з таблицями по кожному семестру (дисципліна, форма контролю, кредити, години).

### Як це працює:
1. **Крок 1 — завантажте Список студентів.** Він зберігається на сервері (у `data/roster.json`) і не потрібно завантажувати його повторно при кожному запуску — досить оновити його, коли зміниться склад груп.
2. **Крок 2 — завантажте РНП** потрібної спеціальності. Сервіс:
   - визначає спеціальність РНП за позначкою в заголовку кожного семестрового блоку (наприклад `(МН)`);
   - зіставляє її з групами зі збереженого списку за префіксом назви групи (`МН-31`, `МН-32`, `МН-41` → спеціальність `МН`); групи інших спеціальностей (наприклад `ФБСФ`, `ІПЗ`) з цього РНП ігноруються — для них знадобиться власний файл РНП;
   - визначає курс групи за другою цифрою її номера (`31`/`32` → 3-й курс, `41` → 4-й курс) і автоматично обирає **семестр, що триває зараз**, за поточною датою (осінь → непарний семестр курсу, весна → парний);
   - для кожної групи будує список дисциплін цього семестру з РНП, автоматично обчислюючи кількість пар (аудиторні години ÷ 2) та тип контролю з форми контролю РНП (`Е/у` → екзамен, `ДЗ` → екзамен/диференційований залік, `З` → залік).
   - **виключає** факультативні дисципліни (позначені `**`), а також практику та захист кваліфікаційної роботи — вони не потребують поточного контролю занять.
   - якщо дисципліна одночасно має іспит і курсову роботу (обидва рядки в РНП) — створюється **і** аркуш іспиту (`ПК_*`), **і** пара аркушів курсової (`КР_*_Зміст`/`КР_*_Захист`).
3. **Крок 3 — перегляд і підтвердження.** На сторінці пакетного перегляду показано кожну знайдену групу з її дисциплінами; можна вказати email викладача для кожної дисципліни (просто як текст у назві вкладки — для власної інформації, нічого не розшаровується автоматично). Один клік — і генерується окремий `.xlsx`-файл для кожної групи, усі разом у одному ZIP-архіві.

### ⚠️ Технічна вимога: antiword
Файли `.doc` (старий бінарний формат Word 97-2003) не читаються бібліотекою `python-docx`. Для їх обробки сервіс використовує утиліту **antiword**, яка вже встановлена разом із **Git for Windows** (`<Git>\mingw64\bin\antiword.exe`) — тобто додаткового встановлення зазвичай не потрібно, якщо на комп'ютері є Git. Якщо Git не встановлено, встановіть antiword окремо і додайте його до PATH.

Файли Список студентів і РНП, а також збережений `data/roster.json`, ніколи не потрапляють у git-репозиторій (додані до `.gitignore`), оскільки містять персональні дані студентів.

## 💻 3. Запуск та користування сервісом

### Крок 1. Запуск локального сервера
Виконайте команду у віртуальному оточенні:
```bash
python app.py
```
У консолі з'явиться повідомлення, що сервер запущено на `http://127.0.0.1:5000/`.

### Крок 2. Імпорт або завантаження даних
Відкрийте браузер і перейдіть за адресою `http://127.0.0.1:5000/`. Ви побачите дві вкладки:

#### Варіант А: Завантажити файл
1. Перейдіть на вкладку **"Завантажити файл"**.
2. Перетягніть або виберіть файл з комп'ютера (підтримуються `.xlsx`, `.xls`, `.csv`, `.docx`).
3. Натисніть кнопку **"Завантажити та переглянути"**.

#### Варіант Б: Імпорт з Google Docs
1. Перейдіть на вкладку **"Імпорт з Google Docs"**.
2. **Важливо:** Надайте доступ до вашого Google Документа (права "Читач" або "Редактор") для сервісного акаунту, адреса якого вказана у кольоровій рамці на сторінці (або зробіть документ доступним для всіх, у кого є посилання).
3. Скопіюйте посилання на ваш Google Документ та вставте його в поле вводу.
4. Натисніть кнопку **"Імпортувати з Google Docs"**.

### Крок 3. Попередній перегляд та створення
На сторінці передогляду ви побачите знайдену назву групи, список студентів та розібрані дисципліни:
1. *(Опціонально)* **Введіть Email викладачів** навпроти кожної дисципліни — це просто позначка, яка з'явиться в назві відповідної вкладки журналу.
2. Натисніть кнопку **"Створити журнал (.xlsx)"**.

### Крок 4. Завантаження та використання
Система згенерує готовий Excel-файл і покаже сторінку з кнопкою **"Завантажити .xlsx"**. Після завантаження:
- Щоб отримати Google Таблицю — просто перетягніть файл у [Google Drive](https://drive.google.com/) у браузері; Drive автоматично конвертує його в Google Таблицю, з якою можна одразу спільно працювати (Файл → Поділитися).
- Або просто відкрийте файл у Microsoft Excel / LibreOffice Calc — усі формули й форматування збережені.

## 📊 4. Розуміння структури згенерованого журналу

Кожен створений журнал містить наступні аркуші:

1. **`ПК_{Дисципліна}`** (Поточний Контроль):
   - Аркуш для оцінювання по кожному дню занять.
   - Стовпчики чергуються: лекція (`л` — 0 балів) та практичне заняття (`п` — бали автоматично розподіляються пропорційно так, щоб сума за семестр дорівнювала макс. 80 балів для заліку або 50 балів для екзамену).
   - Студенти на всіх аркушах, крім першого, автоматично синхронізовані з першим за допомогою посилання `='ПК_{Перша}'!B5`.
2. **`КР_{Дисципліна}_Зміст` та `КР_{Дисципліна}_Захист`** (для курсових проектів):
   - Таблиці оцінювання комісії з 3 членів для детальної перевірки структури та безпосередньо захисту курсової роботи.
3. **`РК1` та `РК2`** (Рубіжний контроль):
   - Автоматично вираховує суму балів, відсоток накопичення та оцінку ECTS/Національну за першу і другу половину семестру.
4. **`ДОД_РК1`, `ДОД_РК2`, `ІНДЗ`, `ДОД_ІНДЗ`** (Додаткові відомості):
   - Журнали обліку додаткових балів та балів за індивідуальні домашні завдання (ІНДЗ макс. 10.0 балів).
5. **`СК`** (Семестровий Контроль):
   - Консолідує семестрові бали студентів на основі сум з РК1, РК2, ІНДЗ та додаткових аркушів.
6. **`В_{Дисципліна}`** (Заліково-екзаменаційні відомості):
   - Аркуші, підготовлені до друку згідно з вимогами університету.
   - ПІБ студентів автоматично скорочується до формату з ініціалами (наприклад: *Козак Є. В.*).
   - Містить формули оцінок («Відмінно», «Зараховано», шкалу ECTS) та повну статистику успішності групи наприкінці аркуша.
7. **`Відомості`** (Зведена семестрова таблиця):
   - Підсумковий дашборд групи, який показує накопичені бали та ECTS/Національну оцінку з усіх дисциплін одночасно.
