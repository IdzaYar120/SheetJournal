# SheetJournal — генератор навчальних журналів

Створює готовий Excel-журнал успішності (`.xlsx`) зі списку студентів і дисциплін:
поточний контроль, рубіжні контролі, ІНДЗ, курсові, відомості з оцінками ECTS.

## Як запустити (Windows)

1. Натисніть **Code → Download ZIP** угорі цієї сторінки та розпакуйте архів.
2. Двічі клацніть **`SheetJournal.exe`**. Встановлювати нічого не потрібно.

Якщо Windows покаже «Windows захистив ваш ПК» — натисніть **Докладніше → Виконати однаково**.
